# 🍽️ ربات تلگرامی رستوران

ربات تلگرامی هوشمند برای رستوران که امکان مرور منو، ثبت سفارش و نمایش ساعت کاری را فراهم می‌کند.

## ✨ ویژگی‌ها

- 📋 **منوی تعاملی**: مرور آسان منوی رستوران
- 🛒 **ثبت سفارش**: انتخاب غذاها و ثبت سفارش آنلاین
- ⏰ **ساعت کاری**: نمایش ساعت کاری روزانه
- 📞 **اطلاعات تماس**: دریافت اطلاعات رستوران
- 💾 **ذخیره‌سازی**: تمام سفارش‌ها در دیتابیس ذخیره می‌شوند
- 🌐 **رابط کاربری دوستانه**: استفاده آسان با دکمه‌های inline

## 📋 نیازمندی‌ها

```bash
pip install -r requirements.txt
```

## ⚙️ راه‌اندازی

### 1. توکن ربات تلگرام

- از [@BotFather](https://t.me/botfather) در تلگرام یک ربات جدید بسازید
- توکن را کپی کنید

### 2. تنظیم config.py

```python
BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE'
```

توکن خود را جایگزین کنید.

### 3. اجرای ربات

```bash
python bot.py
```

## 🎮 راهنمای استفاده

1. ربات را در تلگرام شروع کنید: `/start`
2. از دکمه‌های منو استفاده کنید:
   - **📋 مشاهده منو**: برای دیدن لیست غذاها
   - **⏰ ساعت کاری**: برای دیدن ساعت‌های کاری
   - **📞 تماس با ما**: برای اطلاعات تماس
3. غذاهای مورد نظر را انتخاب کنید
4. سفارش را تایید کنید
5. شماره تلفن و آدرس را وارد کنید
6. سفارش ثبت می‌شود!

## 🗄️ دیتابیس

تمام سفارش‌ها در SQLite ذخیره می‌شوند:
- **user_id**: شناسه کاربر تلگرام
- **username**: نام کاربری
- **items**: لیست غذاها
- **total_price**: مجموع قیمت
- **phone**: شماره تلفن
- **address**: آدرس تحویل
- **status**: وضعیت سفارش
- **created_at**: زمان ثبت

## 🔧 سفارشی‌سازی

### تغییر منو

فایل `config.py` را باز کنید و `MENU` را ویرایش کنید:

```python
MENU = {
    '🍔 برگر': 50000,
    '🍕 پیتزا': 60000,
    # غذاهای خود را اضافه کنید
}
```

### تغییر ساعت کاری

فایل `config.py` را باز کنید و `WORKING_HOURS` را ویرایش کنید:

```python
WORKING_HOURS = {
    'شنبه': '11:00 - 23:00',
    # ساعت‌های خود را تنظیم کنید
}
```
